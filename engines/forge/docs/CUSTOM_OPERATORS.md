# 额外干员包：选择性移植

来源：[Lunac1a / Stronghold-Protocol](https://github.com/Lunac1a/Stronghold-Protocol)，固定提交 `c8141334266fd1d5971ed996d62ac59addb92b5d`。保留来源代码与 GPL-3.0-or-later；机制资料哈希见 custom-operators-provenance.json。

本整合仅开放望、赤刃明霄陈、维什戴尔的三技能，以及凯尔希·思衡托的二技能。技能自动释放。望支持联机手动放置棋子，服务器校验所属玩家、地块、库存、费用与冷却，重复请求不会重复扣费，在线重连保留快照与下一操作序号。

来源另有丰川祥子，本包排除其卡片与技能注册，保留原新干员包的实现。两包可以同时开，丰川祥子只进入卡池一次。也没有移植来源强制保留部分盟约的规则。

数据由工具包 mods/recruits/generate-data.mjs 生成四套追加资料；原四套资料保持独立。召唤物变体合并保留官方 DIY 数据。资源增量入口 tools/fetch-recruits-assets.mjs 使用独立缓存，保留原素材清单。

测试覆盖开放技能的普通/精锐实际伤害、弹药、召唤物、连续技能、手动输入重放、共享卡池购买合成与卖出、联机接管重连。当前整合的检查结果以部署记录为准，不引用来源历史验收数字作为本版本承诺。
